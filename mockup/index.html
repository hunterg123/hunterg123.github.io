CTRL-01Access governance
Kiewit · 2026

Built a quarterly access review from nothing.

A restricted engineering environment needed recurring user access reviews and had no defined process. I wrote the SOP, set the cadence and make the keep-or-remove call on every account. A Power BI report joins the authorized roster to Active Directory group membership, surfaces anyone who lacks required authorization, and routes each removal to a manager or a ticket.
